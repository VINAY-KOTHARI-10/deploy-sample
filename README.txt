MY FIRST DEPLOYMENT WEBSITE

Files:
- index.html: webpage structure
- style.css: page styling
- script.js: button interaction

Run locally:
1. Extract this ZIP file.
2. Open index.html in your browser.

Deploy:
Upload the three website files to a static hosting service such as
Netlify, Vercel (static site), or GitHub Pages.

No build command or environment variables are required.
